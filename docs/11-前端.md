# 前端(最简可展示版)

> 目标:一个 Vue3 页面跑通「登录 → 查票 → 下单 → 轮询 → 支付」全流程,让项目可演示。
> 技术:Vue 3 + Vite + Element Plus + axios。

## 1. 三件套分工(零基础第一课)

| 语言 | 职责 | 类比 |
|---|---|---|
| HTML | 结构:页面上有什么(按钮、输入框、表格) | 毛坯房 |
| CSS | 样式:长什么样(颜色、间距、布局) | 装修 |
| JavaScript | 行为:做什么(点击后发请求、改数据) | 水电系统 |

浏览器只认识这三样——所有前端框架最终都编译成它们。

## 2. Vue 核心思想:数据驱动视图(Java 程序员视角)

传统前端是**命令式**:找到元素 → 改它(`document.getElementById("x").innerText = "新值"`),像手动更新每个 UI 控件。

Vue 是**声明式**:声明「页面 = f(数据)」,你只管改数据,框架自动重渲染。类比:**Vue ≈ 把「页面」变成「数据变化时的自动刷新」**——就像 Java 里你只改字段,所有引用它的地方自动感知(近似响应式的思想)。

核心三件:
- **模板(template)**:HTML + 特殊语法。`{{ data }}` 插值、`v-if` 条件渲染、`v-for` 循环渲染、`@click` 事件绑定
- **响应式数据(ref)**:用 `ref()` 包起来的数据,值一变,用到它的模板位置自动更新
- **组件**:页面拆块,≈ Java 类(有数据 + 方法 + 模板)

## 3. 环境类比

| 前端工具 | Java 类比 |
|---|---|
| Node.js | JRE(运行 JS 的环境) |
| npm | Maven(包管理器,npm install ≈ mvn compile 拉依赖) |
| Vite | 开发服务器(≈ 内嵌 Tomcat,热更新) |
| Element Plus | 组件库(现成的按钮/表单/表格,≈ 一个 UI 工具类库) |
| axios | RestTemplate(发 HTTP 请求) |
| localStorage | 浏览器端的小存储(存 token ≈ 记住会话) |

## 4. Java 概念 → Vue 概念速查

| Java | Vue |
|---|---|
| 类字段 | `const username = ref("")` |
| 方法 | `function handleLogin() {...}` |
| 字符串拼接 | `{{ "你好" + username }}` |
| for 循环 | `v-for="t in trains"` |
| if | `v-if="trains.length > 0"` |
| HTTP 调用 | `axios.post(url, data)` |
| 返回值 | 无(直接改 ref,视图自动更新) |

## 5. 最小页面解剖

```vue
<template>
  <div>
    <input v-model="username" placeholder="用户名" />   <!-- v-model:双向绑定,输入即改数据 -->
    <button @click="handleLogin">登录</button>          <!-- @click:事件绑定 -->
    <p v-if="message">{{ message }}</p>                  <!-- v-if:message 非空才显示 -->
  </div>
</template>

<script setup>
import { ref } from "vue";
import axios from "axios";

const username = ref("");       // 响应式数据
const message = ref("");

async function handleLogin() {
  const res = await axios.post("http://localhost:8081/api/user/login", {
    username: username.value,
    password: "123456",
  });
  message.value = "token: " + res.data.data.token;   // 只改数据,页面自动更新
}
</script>
```

**逐行讲**:
- `v-model="username"`:双向绑定——输入框内容变了 `username` 变,`username` 变了输入框变
- `@click="handleLogin"`:点击事件 → 调函数(≈ Java 的事件监听器)
- `const username = ref("")`:响应式字段,模板里写 `username`,脚本里必须写 `username.value`(模板自动解包)
- `await axios.post`:发 HTTP(≈ RestTemplate),`await` 等结果(≈ 同步调用)
- 函数里**没有 return、没有改页面**——只改 `message.value`,`<p v-if>` 自动出现

## 6. 项目结构(与 Spring Boot 类比)

```
ticket-web/
├── package.json        ≈ pom.xml(依赖清单)
├── vite.config.js      ≈ application.yml(构建/代理配置)
├── index.html          入口页
└── src/
    ├── main.js         ≈ main 方法(挂载根组件)
    ├── App.vue         ≈ 主类(根组件,组装各页面)
    └── api.js          统一 axios 封装(≈ 服务层,发请求的地方)
```

## 7. 任务清单(最简可展示版)

1. **环境**:装 Node.js(≥18)+ npm
2. **脚手架**:`npm create vite@latest ticket-web -- --template vue`(一条命令生成工程)
3. **依赖**:`npm install element-plus axios`
4. **一个页面**:登录框 → 车次列表(查票)→ 选择车次 → 乘车人 → 下单 → 轮询排队(定时器)→ 支付按钮 → 最终状态展示
5. **关键细节**:
   - token 存 localStorage,之后每个请求带 `Authorization: Bearer <token>` 头
   - 下单后拿 requestId,`setInterval` 每 2 秒轮询 `/api/order/status`(对应阶段五的排队页!)
   - 跨域:前端跑 5173(Vite 默认),后端 8081——用 Vite 的 proxy 配置转发(开发期方案,生产同域)
6. **验收**:浏览器打开页面,走通全流程
